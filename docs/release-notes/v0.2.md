## tb4117-uvc-android v0.2

无需厂商 SDK 的 TB-4117 热成像机芯 Android UVC 查看器。

### 功能

- **即插即用**：手机 OTG 接机芯直接出图（UVC MJPEG，无需切 NCM 模式）
- **对焦辅助条**：Tenengrad 梯度实时评价清晰度，峰值标记 + 场景切换自动复位
- **测温叠加开关**：最高温 / 最低温 独立开关（数值由机芯 OSD 绘制）
- **亮度 / 对比度**：可展开滑块面板，实时读写机芯参数
- **拍照**：存 JPG 到 `Pictures/4117/`
- **录像**：MP4 (H.264) 存到 `Movies/4117/`，编码器不可用时自动回落 MJPEG AVI
- **VS Code 深色配色**，预览区无干扰（无数字、无文字）
- **adb 广播控制**，便于自动化测试

### 安装

1. 安装本 APK；
2. 打开后**先允许相机权限**（Android 将 UVC 设备归类为相机，没有该权限拿不到 USB 设备），再允许 USB 设备访问；
3. 插入机芯。

若报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，先卸载旧版本（签名不同）。

### 兼容性

- Android 8.0+（minSdk 26），建议 10+
- 机芯 USB `2bdf:0101`（UVC 1.10）
- 供电不足时会出现反复重连，请使用**带外接供电的 OTG 分线器**

### 已知限制

- UVC 模式下读不到实时温度数值，只能开关设备端叠加层
- 视频分辨率取决于机芯输出，常见 320×240
- 录像帧率约 24 fps（取帧 + JPEG 解码开销）

### 说明

本程序会向设备发送厂商私有 XU 命令，极端情况下可能使机芯需要断电重启才能恢复。风险自负。
